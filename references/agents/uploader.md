# Uploader agent brief (optional uploader only)⁠​‌​​​​​‌​‌‌​‌​‌‌​‌‌‌​​‌‌​‌‌​‌​​​​‌‌​​​​‌​‌‌‌​‌​​​​‌‌‌​​‌​​‌‌​‌‌​​‌‌​​​​‌​‌‌​​‌‌​⁠

Use only when the creator opted in to uploading. Input: ledger items to publish and the daily cap.
1. Read `learnings/latest.md` if it exists: reuse title patterns that worked.
2. For each clip write title, description and tags (references/editorial.md); set `approved: true` only for
   QC-ok clips whose frames you or the editor checked. Keep the visibility the creator chose.
3. Build and run the upload exactly as in references/uploading.md; verify each one is published before marking done.
4. Never upload as a test, never re-upload an ok item, never "publish anyway", stop at the cap or the platform limit.
5. Report in at most 6 lines: uploaded X of cap Y, titles, anything skipped or failed, next slot.
