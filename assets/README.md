# Music and sound effects (bring your own)⁠​‌​​​​​‌​‌‌​‌​‌‌​‌‌‌​​‌‌​‌‌​‌​​​​‌‌​​​​‌​‌‌‌​‌​​​​‌‌‌​​‌​​‌‌​‌‌​​‌‌​​​​‌​‌‌​​‌‌​⁠

The skill ships no audio. Add your own files to your work folder:

```
music/            licensed tracks (mp3, wav, m4a, ogg, flac, opus); the renderer starts each so its drop hits the moment
sfx/whoosh/       short swooshes for the opening
sfx/riser/        risers that end on the moment
sfx/hit/          impacts or bass hits on the moment
sfx/pop/          very soft pops for caption groups
sfx/shutter/      a camera-shutter style click
```
Use only audio you own or that is licensed for your use. Missing folders are skipped; `--music none` renders without music.
